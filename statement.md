# Project Statement

## Problem Statement

Communication can be difficult between people who use American Sign Language (ASL) and people who are not familiar with sign language.

The objective of this project is to develop a computer vision-based system that can recognize predefined ASL hand gestures from a webcam and display the predicted gesture in real time.

## Scope

The project focuses on real-time recognition of predefined American Sign Language hand gestures using a webcam, computer vision techniques, and a KNN-based machine learning model.

The system is intended to recognize the gesture classes supported by the trained model. It does not aim to provide complete sentence-level sign language translation.

## Target Users

- Students learning or experimenting with computer vision
- ASL learners
- People interested in sign language recognition
- Developers interested in real-time gesture recognition

## High-Level Features

- Real-time webcam input
- Hand detection and tracking
- Gesture processing
- KNN-based ASL gesture classification
- Real-time prediction display
